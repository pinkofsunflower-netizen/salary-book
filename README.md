# สมุดเงินเดือน + Firebase: คู่มือติดตั้ง

## ในโฟลเดอร์นี้มีอะไรบ้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `public/index.html` | หน้าเว็บหลัก (ภาพรวม เงินเดือน งบรายเดือน ภาษี) |
| `public/import.html` | หน้านำเข้าข้อมูลจากไฟล์ Excel เข้า Firebase |
| `public/sheet-parser.js` | ตัวอ่านชีต Excel รูปแบบเดียวกับชีต 2025 |
| `public/firebase-config.js` | **ไฟล์เดียวที่ต้องแก้** ใส่ค่า config ของโปรเจกต์ |
| `firestore.rules` | กฎความปลอดภัย ให้แต่ละคนเห็นเฉพาะข้อมูลตัวเอง |
| `firebase.json` | ตั้งค่า Firebase Hosting |

ข้อมูลจะเก็บใน Firestore ที่ `users/{uid}/years/y2025`, `users/{uid}/years/y2026` ไปเรื่อย ๆ (หนึ่งเอกสารต่อหนึ่งปี)

---

## ขั้นที่ 1: สร้างโปรเจกต์ Firebase

1. เข้า https://console.firebase.google.com แล้วกด **Create a project** (หรือ Add project)
2. ตั้งชื่อ เช่น `salary-book` กด Continue จนเสร็จ (Google Analytics ปิดได้)

## ขั้นที่ 2: เปิดการเข้าสู่ระบบด้วย Google

1. เมนูซ้าย **Build → Authentication** กด **Get started**
2. แท็บ **Sign-in method** เลือก **Google** → เปิด Enable → เลือกอีเมลสำหรับ support → Save

## ขั้นที่ 3: สร้างฐานข้อมูล Firestore

1. เมนูซ้าย **Build → Firestore Database** กด **Create database**
2. เลือก location ใกล้ไทย เช่น `asia-southeast1 (Singapore)`
3. เลือก **Start in production mode** แล้วกด Create
4. ไปแท็บ **Rules** ลบของเดิม วางเนื้อหาจากไฟล์ `firestore.rules` แล้วกด **Publish**

> ถ้าข้ามข้อ 4 หน้าเว็บจะขึ้นว่า "ไม่มีสิทธิ์อ่านข้อมูล" เพราะ production mode ปิดการอ่านเขียนทั้งหมดไว้

## ขั้นที่ 4: เอาค่า config มาใส่

1. กดรูปเฟือง ⚙️ ข้าง Project Overview → **Project settings**
2. เลื่อนลงที่ **Your apps** กดไอคอน **</>** (Web)
3. ตั้งชื่อแอป เช่น `web` กด Register app (ไม่ต้องติ๊ก Hosting ตรงนี้)
4. จะเห็นโค้ด `const firebaseConfig = { ... }` ให้คัดลอกค่าในวงเล็บปีกกา
5. เปิดไฟล์ `public/firebase-config.js` แล้ววางทับค่า `ใส่_...` ทั้งหมด

ตัวอย่างหลังแก้:

```js
export const firebaseConfig = {
  apiKey: "AIzaSyB...",
  authDomain: "salary-book.firebaseapp.com",
  projectId: "salary-book",
  storageBucket: "salary-book.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
```

> ค่า apiKey ของ Firebase ฝั่งเว็บไม่ใช่รหัสลับ ใส่ในไฟล์ได้ตามปกติ ความปลอดภัยของข้อมูลมาจาก Firestore rules ในขั้นที่ 3

## ขั้นที่ 5: นำเว็บขึ้น Firebase Hosting

ต้องมี Node.js ในเครื่องก่อน (ดาวน์โหลดจาก https://nodejs.org) แล้วเปิด Terminal (Mac) หรือ Command Prompt (Windows) ที่โฟลเดอร์นี้

```bash
npm install -g firebase-tools     # ติดตั้งครั้งแรกครั้งเดียว
firebase login                    # เข้าสู่ระบบบัญชี Google เดียวกับที่สร้างโปรเจกต์
firebase use --add                # เลือกโปรเจกต์ salary-book แล้วตั้งชื่อเล่นว่า default
firebase deploy                   # อัปโหลดเว็บและ Firestore rules
```

เสร็จแล้วจะได้ลิงก์ประมาณ `https://salary-book.web.app` เปิดได้ทั้งมือถือและคอม

> **ทดลองในเครื่องก่อนก็ได้** ด้วยคำสั่ง `firebase serve` แล้วเปิด http://localhost:5000
> ห้ามเปิดไฟล์ด้วยการดับเบิลคลิก (`file://...`) เพราะ Google sign-in และโมดูล JavaScript จะไม่ทำงาน

## ขั้นที่ 6: นำเข้าข้อมูลจาก Excel

1. เปิดเว็บ แล้วกด **เข้าสู่ระบบด้วย Google**
2. กดปุ่มลูกศรลง ⤓ มุมขวาบน (หรือปุ่ม "นำเข้าจาก Excel" ตอนยังไม่มีข้อมูล)
3. เลือกไฟล์ `Tax_Year_2026.xlsx`
4. หน้าเว็บจะแสดงทุกชีตที่อ่านได้ ชีต **2023, 2024, 2025, 2026** จะถูกเลือกไว้ให้ (ชีต "คำนวณภาษี 2023/2024" ปีซ้ำ จึงไม่ถูกเลือก)
5. กด **นำเข้า** แล้วกลับไปหน้าหลัก เปลี่ยนปีได้ที่ปุ่มปีมุมขวาบน

ปีต่อ ๆ ไป ถ้ายังทำ sheet แบบเดิม ก็นำเข้าแบบเดียวกันได้เลย ถ้านำเข้าปีที่มีอยู่แล้ว ข้อมูลปีนั้นใน Firebase จะถูกแทนที่ (ระบบจะถามยืนยันก่อน)

### ตัวอ่านชีตทำงานอย่างไร
- **ตารางเงินเดือน**: หาหัวคอลัมน์ "เงินเดือนที่ได้" แล้วจับคอลัมน์จากชื่อหัวตาราง จึงรองรับชีตที่มีคอลัมน์ **กยศ.** (2023, 2024) ด้วย ยอดนี้จะเข้าช่อง "หักอื่น" และหักออกจากเงินที่ได้
- **หมายเหตุและวันลา**: อ่านจากคอลัมน์ หมายเหตุ ลาป่วย ลากิจ ลาพักร้อน อื่นๆ วันที่จะแปลงเป็นรูปแบบ วัน/เดือน/ปี
- **เดือนที่มี 2 แถว** (เช่น ตุลาคม): แถวที่ไม่หักประกันสังคมและกองทุนจะติดป้าย "โบนัส"
- **การ์ดงบรายเดือน**: หาเซลล์ "เดือน" ที่ช่องถัดไปเป็นชื่อเดือน (รองรับชื่อเดือนพิมพ์ผิดเล็กน้อย เช่น "มิถุยายน") อ่านรายการจนถึง "กดเงินสด" หรือการ์ดถัดไป
- **ยอดคงเหลือและกดเงินสด**: อ่านจากสูตรใน sheet ว่ารวมรายการไหนบ้าง รายการที่สูตรคงเหลือไม่ได้รวมไว้ จะติดป้าย **"ไม่นับในงบเดือนนี้"** ตัวเลขในเว็บจึงตรงกับ sheet ทุกเดือน และเปิดปิดป้ายนี้เองได้ในหน้าแก้ไขรายการ
- **ป้ายเงินออม**: รายการที่ขึ้นต้นด้วย เงินออม, เก็บเงิน, เงินเก็บ, เงินสำรอง, โบนัส
- **ค่าลดหย่อนอื่น** และ **กฎแบ่งเงิน** อ่านจากบล็อกด้านขวาของชีต

ชีต 2023 ไม่มีการ์ดงบรายเดือน จึงนำเข้าเฉพาะเงินเดือน ภาษี และกฎแบ่งเงิน ส่วนชีต 2024 มีงบตั้งแต่มีนาคมถึงธันวาคม

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ขึ้น "ยังไม่ได้ตั้งค่า Firebase" | ยังไม่ได้แก้ `firebase-config.js` หรือแก้แล้วยังไม่ `firebase deploy` |
| กดเข้าสู่ระบบแล้วขึ้น `auth/unauthorized-domain` | Authentication → Settings → Authorized domains → เพิ่มโดเมนที่ใช้ |
| กดเข้าสู่ระบบแล้วขึ้น `auth/operation-not-allowed` | ยังไม่ได้เปิด Google ในขั้นที่ 2 |
| ขึ้น "ไม่มีสิทธิ์อ่านข้อมูล" หรือ `permission-denied` | ยังไม่ได้วาง rules ในขั้นที่ 3 ข้อ 4 หรือรัน `firebase deploy` อีกครั้ง |
| มือถือกดเข้าสู่ระบบแล้วไม่มีอะไรเกิดขึ้น | ปิดตัวบล็อกป๊อปอัป หรือเปิดลิงก์ด้วย Safari/Chrome แทนเบราว์เซอร์ในแอปแชท |
